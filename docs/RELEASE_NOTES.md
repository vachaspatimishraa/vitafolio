# Release Notes - Vitafolio v1.0.0

## Overview
We are excited to announce the first official release of Vitafolio, the ultimate offline-first resume builder. Vitafolio empowers users to create stunning, professional resumes directly on their mobile devices without needing an internet connection.

## Key Features
- **Offline Reliability**: Your data never leaves your device. Edit and manage resumes anywhere, anytime.
- **Dynamic Previews**: See exactly how your resume looks as you type.
- **Pro Templates**: Five expertly designed templates tailored for different industries and styles.
- **One-Click Export**: Generate a high-quality PDF in seconds and share it via your favorite apps.
- **Effortless Management**: Organize your resumes with a clean, modern dashboard.

## New in this Version
- First public release!
- Core resume sections supported: Personal Info, Summary, Experience, Education, Skills, Projects, Certifications, and Languages.
- Integrated search and filtering.

## Known Issues
- Image support (profile photos/logos) is planned for a future update.
- Currently optimized primarily for Android devices.

## What's Next
- Cloud sync and multi-device support.
- AI-powered content suggestions.
- More customizable templates.
